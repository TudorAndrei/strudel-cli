Install

One command with mise.

mise downloads the matching executable from the latest GitHub release. You can also download an archive.

mise use -g github:TudorAndrei/strudel-cli@latest

For one project, remove -g.

strudel check song.strudel
strudel query song.strudel --from 0 --to 4

For agents

A small, clear command path.

The CLI returns one JSON object on standard output for query, describe, and check --json. A failed command exits with code 1.

  1. 1

    Inspect the contract

    strudel describe returns the current command and result shapes.

  2. 2

    Check a file

    strudel check song.strudel --json --limit 0 checks one cycle and returns the event count.

  3. 3

    Query only what you need

    strudel query song.strudel --from 0 --to 4 --limit 16 limits the event list. eventCount still reports the full count.

What the check covers

The command evaluates the file as JavaScript and queries the selected cycle range. Run source files that you trust.

A successful check covers that range. It does not verify audio samples or produce sound.
